# 双网平衡的低碳交通流系统智能调度系统

指标：搭建双网能耗模型及原型系统，至少支持平峰及异常两种不同典型场景的双网融合新能源公共交通调度验证

目标：使用streamlit框架，展示系统能力与效果。

## 首页：展示3个板块（页面）的关联

关联：
- 页面1是建模预测，为后续提供模型支撑
- 页面2是鲁棒优化，为页面3提供场景支撑
- 页面3是协同调度，包含两个板块，电价调控和交通流调度，这两部分落脚于电网和路网，形成一个整体的双网平衡智能调度

点击某个模块可以跳转到具体页面


## 页面1: 双网能耗模型与多尺度时空预测

- 关键指标：提出数据驱动的双网能耗模型及能耗预测方法，可覆盖长短期预测，在所构建的数据集上较现有代表性方法预测误差降低5%以上


## 页面2: 基于大时空尺度不确定场景下的鲁棒性充电站选址与容量优化

- 关键指标：提出数据驱动的双网能耗模型及能耗预测方法，可覆盖长短期预测，在所构建的数据集上较现有代表性方法预测误差降低5%以上


## 页面3: 基于协同与博弈的新能源动态电价调控与公共交通流调度

- 关键指标：建立双网互影响模型，设计基于超启发、迁移演化优化、协同演化、演化博弈的适应性动态电价调整策略和大规模新能源公共交通流调度算法，通过在原型系统上开展仿真验证，实现城市级交通拥堵时间减少8%以上,电网峰值负荷降低8%以上
